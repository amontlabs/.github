<i>Practical, open-source software on emerging tech.</i>

### Apps

**[Fjord](https://github.com/amontlabs/fjord)** — The power without the storm. A macOS app between your coding agents and everything they work with (GitHub, CI, Claude Code sessions) that brings you only what needs your attention. *WIP.*

**[Sic](https://github.com/amontlabs/sic)** — Live fact-checking of political debates against official sources. *Heavy WIP.*

**[Hartlib](https://github.com/amontlabs/hartlib)** — One research chat across everything you subscribe to, with every answer cited. *Paused for now.*

### Libraries

**[Silo](https://github.com/amontlabs/silo)** — Computers for agents: sandboxed Linux and macOS VMs with a desktop and computer use. The engine behind Fjord's agent computers.

**[LCU](https://github.com/amontlabs/lcu)** — Codex computer use, decoupled from the app, for any agent harness.

**[lastdrop](https://github.com/amontlabs/lastdrop)** — Use any model as a built-in subagent in Claude Code, with a subscription or API key, and spread usage across your accounts.
